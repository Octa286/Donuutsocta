# 🍩 Donut´s Octa

## Descripción del proyecto

**Donut´s Octa** es un sitio web creado para un emprendimiento de repostería artesanal dedicado a la venta de donas y flanes. Su propósito es presentar los productos de manera atractiva, dar a conocer el negocio y facilitar a los clientes la realización de pedidos mediante WhatsApp.

El sitio cuenta con un diseño moderno, juvenil, visualmente atractivo y adaptable a diferentes dispositivos, utilizando una combinación de colores azul cielo, blanco, rosa pastel y café chocolate.

## 🎯 Objetivo

Crear una página web que permita dar a conocer los productos de Donut´s Octa, mostrar su catálogo de donas y flanes, proporcionar información sobre el emprendimiento y facilitar la comunicación con los clientes para realizar pedidos.

## 📄 Estructura del sitio web

El proyecto cuenta con tres páginas principales:

### 1. Inicio (`index.html`)
- Sección de bienvenida.
- Logo del emprendimiento.
- Presentación de los productos.
- Sección "Sobre nosotros".
- Apartado de donas.
- Apartado de flanes.
- Galería de tres imágenes adicionales.
- Botones para realizar pedidos.

### 2. Catálogo de donas (`donas.html`)
- Presentación del catálogo.
- Imágenes de las donas.
- Nombre y precio de cada producto.
- Botones de pedido mediante WhatsApp.

### 3. Catálogo de flanes (`flanes.html`)
- Presentación del catálogo de flanes.
- Imágenes de los productos.
- Nombre y precio.
- Botones de pedido mediante WhatsApp.

## ⚙️ Funcionalidades

- Navegación entre las diferentes páginas.
- Catálogo visual de productos.
- Información y precios de cada producto.
- Botones funcionales para realizar pedidos.
- Integración con WhatsApp.
- Diseño responsive para computadoras, tablets y celulares.
- Efectos visuales y animaciones suaves.
- Tarjetas de productos con bordes redondeados y sombras.
- Enlaces para regresar a la página principal.

## 🎨 Diseño

La identidad visual del sitio se basa en una combinación de colores pastel y tonos relacionados con la repostería.

| Color | Uso |
|---|---|
| Azul cielo | Fondos y elementos principales |
| Blanco | Fondos, tarjetas y espacios visuales |
| Rosa pastel | Detalles decorativos y acentos |
| Café chocolate | Textos, detalles y elementos relacionados con los productos |

El diseño utiliza tipografía moderna, esquinas redondeadas, sombras suaves, transiciones y una distribución ordenada de los elementos.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** diseño, estilos, animaciones y adaptación responsive.
- **JavaScript:** funcionalidades e interacciones del sitio web.
- **WhatsApp:** comunicación directa para la realización de pedidos.
- **Bolt:** herramienta utilizada para desarrollar y construir el proyecto web.

## 🖼️ Imágenes

El proyecto utiliza imágenes proporcionadas por el propietario del emprendimiento. Estas imágenes se emplean para mostrar los productos, el logotipo, la presentación del negocio y la galería.

Las imágenes originales se conservan, permitiendo únicamente ajustes de tamaño, posición y acomodo visual para adaptarlas al diseño de la página.

## 🚀 Cómo ejecutar el proyecto

1. Descargar o clonar el proyecto.
2. Abrir la carpeta del proyecto.
3. Localizar el archivo `index.html`.
4. Abrirlo en un navegador web, como Google Chrome.
5. Navegar por las secciones y probar los botones y enlaces.

También puede ejecutarse desde Visual Studio Code utilizando la extensión Live Server.
